# ADR 0001：基金详情页净值走势图采用双轴 + 起点对齐

- 日期：2026-05-17
- 状态：已实施（commit 待定，紧随本 ADR 之后）
- 上下文范围：`components/nav-chart.tsx`、详情页 `app/funds/[code]/page.tsx`

## 背景

基金详情页需要同时展示**单位净值**与**累计净值**两条曲线。两者数值差异可能很大：
- 频繁分红的老基金，累计净值往往是单位净值的 2~5 倍
- 从未分红的基金，两者完全重合
- 单一 Y 轴下，累计净值远高于单位净值时，单位净值的波动会被压扁到几乎看不出来

直接画两条线（共用 Y 轴）已尝试过：累计净值把 Y 轴拉高后，单位净值波动几乎不可见。

## 备选方案

1. **共用 Y 轴**：实现简单，但对分红多的基金信息密度低，单位净值波动看不清。已弃用。
2. **切换按钮（toggle）**：一次只看一条。能看清波动，但无法直观对比"分红回报"和"价格波动"。曾实现，用户反馈不直观。
3. **双轴 + 起点对齐 + 单位相同**：左轴单位净值、右轴累计净值，右轴整体平移 `offset` 使首个采样点两条线视觉重合，**单位长度完全相同**。
4. **百分比归一化**：把两条线都归一化到 100% 起点。能看出对比但丢失绝对数值。

## 决策

采用 **方案 3（双轴 + 起点对齐 + 单位相同）**。

### 数学

令首个有 `acc_nav` 的采样点为 anchor：

```
offset = anchor.acc_nav - anchor.unit_nav
```

两轴 domain：

```
left  domain = [yMin,           yMax]
right domain = [yMin + offset,  yMax + offset]
```

其中 `yMin`/`yMax` 是把所有 `unit_nav` 与 `(acc_nav - offset)` 合并后取的极值（加 2% 留白）。这样保证：
- 两轴**单位长度相同**（每像素代表的数值变化量一致）
- 在 chart 起点的 x 坐标处，两条线 y 像素重合
- 两条线在整个范围内都不被裁切

### 视觉语义

- 单位净值：蓝色 `#2563eb`（主体观察对象）
- 累计净值：灰色 `#9ca3af`（参考/背景信息）
- 线型：`linear`（直线段，不平滑）
- 累计净值缺失数据点 `connectNulls` 连接跨过
- **z-order**：累计净值先渲染（垫底），单位净值后渲染（置顶）。两线重合区域优先展示单位净值，与"主体观察对象"语义一致

## 后果

**正面**：
- 单位净值波动还原其本来振幅，不被累计净值"压扁"
- 起点对齐让人一眼看出"分红回报"的累积差距（两条线在起点重合，越往右分开越多 = 分红越多）
- 单位相同意味着两条线的"斜率"等同于"日涨跌幅"，可直接对比波动剧烈程度
- 共享 X 轴，鼠标 hover 同步显示两个值

**负面**：
- 右侧 Y 轴的刻度不是从 0 开始，新用户可能误读为"两条线本来就不一样长"。已通过 Legend + 起点重合的设计让对比意图明确
- 没有 `acc_nav` 数据的基金降级为单线（无右轴），略增加渲染分支

**适用范围**：仅基金详情页 NavChart。其他图表（如未来的"持仓收益对比"）若涉及多基金对比，可能更适合归一化方案，需另议。
